# CityTrail frontend

React 19 + TypeScript on Vite+. See the root `README.md` for setup.

- `npm run dev` starts the dev server on http://localhost:5173 and proxies `/api` to the Spring Boot backend on :8080.
- `npm run build` type-checks and builds to `dist/`.
- `npm run lint` runs Oxlint through `vp lint`.
